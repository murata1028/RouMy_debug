# RouMy新方針における RouMy_debug の役割

本リポジトリの全体戦略ドキュメントは `murata1028/RouMy` の `docs/STRATEGY.md`（ブランチ `claude/roumy-strategy-redesign-1e9fb0`）を参照してください。

## このリポジトリの新しい位置づけ

新方針では、RouMy本体は「地図＋時刻表」から「JR東日本方式の縦型旅程プランナー＋乗る前確認OCR」へ構造転換する（詳細は本体リポジトリのSTRATEGY.md参照）。

それに伴い、本リポジトリ（`debug.html`）は次の役割に位置づける。

- **本体アプリの技術検証専用ツールとして維持する。**
- 今後追加される経路探索エンジン（GTFSベースの多区間乗換探索）や、乗る前確認OCRの期待系統番号照合ロジックのデバッグ出力先として活用する。
- 本体アプリのユーザー向け機能をここに実装しない（デバッグ用途に限定する）。

詳細な背景・全体戦略は本体リポジトリの STRATEGY.md を参照。
